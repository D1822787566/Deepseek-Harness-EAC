# 离线市场筛选按钮设计

## 目标

在插件市场现有筛选栏中增加“仅看离线包”按钮，让用户快速查看安装包内已经缓存、可断网安装的插件。

## 交互

- 按钮位于“已安装”筛选按钮旁，沿用现有 `mkts-chip` 视觉样式。
- 默认关闭；点击后仅显示 `offline === true` 的插件，再次点击恢复。
- 按钮显示离线包总数。该数字来自完整目录，不受搜索词、分类或其他筛选条件影响。
- 离线筛选与搜索、分类、排序、“已安装”和“显示实验性内容”叠加生效。
- 开关离线筛选不重置当前分类、搜索词、排序、已安装筛选或实验性内容设置。
- “已安装”与“仅看离线包”可以同时启用，表示查看既已安装、又存在于离线包内的插件。
- 组合筛选没有结果时，继续使用现有“没有匹配的插件”空状态。
- 中文标签为“仅看离线包”，英文标签为“Offline only”。

## 实现边界

- 仅修改 `dsh-webui-market` 的浏览器端筛选逻辑和对应测试。
- 不修改离线 manifest、host API、安装流程或缓存格式。
- 不新增独立页面、分类或持久化设置。

## 数据流

1. 市场 host 继续使用 `stampCatalogPlugins` 为缓存命中的目录条目设置 `offline: true`。
2. 市场客户端从完整插件目录计算离线包总数。
3. 用户开启筛选后，客户端在现有过滤管线中追加 `offline === true` 条件。
4. 过滤结果继续进入现有排序和分组逻辑。

## 测试与验收

- 默认状态不会排除在线条目。
- 开启后只保留 `offline === true` 的条目。
- 离线筛选能与搜索、分类、已安装和实验性内容规则叠加。
- 离线总数来自完整目录，不随当前筛选结果变化。
- 按钮使用现有激活态样式，并显示中英文标签。
- 市场相关测试和项目全量测试通过。
